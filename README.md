# VeraLevel Media — Landing Page

## Run it

1. Install Node.js LTS from https://nodejs.org (skip if installed)
2. Open this folder in VS Code, then in the terminal:

   npm install
   npm run dev

3. Open the local address it prints (usually http://localhost:5173)

## Deploy it

   npm run build

Then drag the generated `dist` folder into Netlify, or connect the repo to Vercel.

## Before going live

- Replace the placeholder alert on the "Book Your Free Strategy Call" button
  in `src/App.jsx` with your real WhatsApp / Calendly / booking link.
- Logo files are in `public/logos/` if you need them elsewhere.
